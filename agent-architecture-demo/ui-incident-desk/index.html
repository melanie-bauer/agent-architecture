Who decides where

  • Code picks the path, removes customer data and makes the change.
  • A model fills two open boxes: classify and investigate.
  • A person approves or declines.

  1. load-ticket

    Code

    Loads the ticket and removes customer data, once, at the entrance.

  2. classify

    Small model, no tools

    Labels severity, service and category in a fixed schema.

  3. branch

    Code

    An if statement on the severity picks the path.

  4. create-backlog-item

    Code, sev3 only

    Files the ticket. Nothing else runs.

  5. investigate

    Large model, supervisor

    The investigator asks logAnalyst and deployHistorian and proposes one action. It holds no write tools.

  6. approve-remediation

    Person

    The workflow suspends and waits for your decision as stored state.

  7. execute-remediation

    Code

    Plain code checks the allow list and runs the change, or hands over to on-call.
